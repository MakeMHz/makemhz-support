## Important Notes

- **Remote power-on must be initialized first.** After installing or updating, the Xbox must be powered on
manually at least once before remote power-on will work. If the Xbox is disconnected from AC power, it must
be powered on manually again before remote power-on becomes available.
- **BlueRetro firmware updates are included with Stellar firmware updates.**
You do not need to update BlueRetro separately.
- **Auto sync is enabled by default.** When no wireless controller is connected, BlueRetro will automatically
enter sync mode. Stellar modifies this behavior by adding a 60-second timeout to help avoid conflicts with other
nearby Bluetooth hosts.
- **BlueRetro configuration is available through the BlueRetro web configurator:** [https://blueretro.io/](https://blueretro.io/)

  If a controller is already connected, you must either enter scanning mode from StellarOS or disconnect the
controller before using the configurator.
